# Drawers

Group the apps on your Windows 11 taskbar into drawers. Pin a drawer, click it, and the apps for that job drop down like a menu Windows made itself.

This repository holds the installer downloads only. Everything about the app is at **https://pocketforgestudios.com/drawers/**.

## Download

Get the latest `DrawersSetup` file from the [Releases](../../releases/latest) page.

- Free with one drawer.
- Installs just for you, with no administrator prompt.
- Uninstalls from Settings > Apps.

## Windows will ask you to confirm

Drawers is new and its installer is not yet signed with a publisher certificate, so Windows shows a blue "Windows protected your PC" box. Choose **More info**, then **Run anyway**.

To check a download is exactly the file we published, compare its SHA-256 fingerprint with the one in the release notes:

```powershell
Get-FileHash DrawersSetup-1.12.0.exe
```

## Privacy

No account and no tracking. Your drawers stay on your PC. The only thing Drawers does online is look for a new version, and you can switch that off.
